# Event Booking App

A full-stack Event Booking web application where users can explore events, register/login, and book events online.

---

## Features

- User Authentication (Login/Register)
- Event Listing
- Event Booking System
- User Dashboard
- Responsive UI
- MongoDB Database Integration
- Secure Environment Variables using `.env`

---

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- EJS

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
